# One-Line Roast: The Gadget You Use Every Day

A one-line roast of my wireless earbuds — the left one always dies
mid-sentence while the right one still claims plenty of charge. Written
for the make.fun bounty
[One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610?utm_source=github&utm_medium=readme&utm_campaign=u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out node main.ts
cat /tmp/roast-out/entry.txt
```

`main.ts` (Node 22, standard library only) writes exactly one line —
the roast, 1–200 characters, no trailing newline — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else. It is fully
deterministic: the same line every run.
